## 📄 Descrição

Com a missão de promover a democratização de dados, extração de insights e decisões certeiras, nasceu a Money BR. O projeto tem a missão de auxiliar a empresa [Pic Money](https://www.picmoney.shop/), parceira da FECAP, com a análise de dados dos seus negócios. Dessa forma, trabalhamos continuamente em trazer visões que possibilitassem entender a volumetria de transações dos cupons, dados demográficos dos clientes, lojas com maior rentabilidade, receita bruta, receita líquida, ticket médio e demais. Com isso, fizemos uma divisão entre CEO (Chief Executive Officer) e CFO (Chief Financial Officer), com dados gerais e dados financeiros, respectivamente.
